# Изображения тем

14 изображений из подписанного архива, предоставленного владельцем проекта.
Названия файлов соответствуют ID тем из `shared/theme-artwork.js`.
Используются в выборе интересов и синтетических демокарточках.
Лицензия архива отдельно не предоставлена; права на дальнейшее распространение
должны быть подтверждены владельцем. Реальные дела используют фото источника.
